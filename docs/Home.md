# 📖 Welcome to the Hopper Filter Wiki

**Hopper Filter** is an elegant, vanilla-friendly Minecraft mod for **NeoForge 1.21.1** created by **MitraFun**. It simplifies automation and item sorting by turning standard vanilla hoppers into intelligent filters using ordinary **Item Frames**.

## 🚀 Quick Start in 3 Steps

1. **Place a Hopper**: Put down a standard Minecraft hopper connected to any chest or container.
2. **Attach an Item Frame**: Place an **Item Frame** (or **Glow Item Frame**) on any of the hopper's side faces.
3. **Set the Filter**: Right-click the item frame with the item you want to filter (e.g., *Iron Ingot*).

> 🎉 **That's it!** The hopper will now **only** accept, suck in, or pull *Iron Ingots*. All other items are ignored or passed along.

## 🌟 Why Use Hopper Filter?

| Feature | Vanilla Redstone Sorters | Hopper Filter |
|---|---|---|
| **Footprint** | 3x1x3 blocks per slice | 1x1x1 (Single hopper block!) |
| **Redstone Complexity** | Comparators, Repeaters, Redstone Dust, Torches | Zero redstone required |
| **Multi-Item per Chest** | Very difficult & bulky | Up to 6 different items per hopper |
| **Server Performance / Lag** | High (frequent comparator & redstone updates) | Near zero (instant lightweight checks) |
| **Aesthetic** | Hidden behind walls | Clean, visual item display |
